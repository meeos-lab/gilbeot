# 사전 등록 문서의 git 이력

이 표는 git 이력에서 스크립트로 뽑았다. 등록 문서의 각 절은 본문에 '결과를 보기 전에 고정'이라고 적혀 있지만, git 커밋 시각으로 그 순서를 뒷받침할 수 있는 것은 절을 더한 커밋과 '결과를 본 뒤 추가' 기록을 더한 커밋이 다른 경우뿐이다. 한 커밋에 절과 기록이 함께 들어간 경우(표 아래 목록)와 본 실험 뒤에 만들어진 첫 커밋의 절들은 등록 시점이 문서 안의 진술과 실행 로그(server/link/sim/results/*_pc.log)의 시각으로만 뒷받침된다. 검증은 저장소의 `git log -p -- docs/sim-preregistration.md` 로 한다.
